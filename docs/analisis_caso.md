# Análisis del caso — VerifiPay SpA

## Contexto
VerifiPay es una fintech ficticia de pagos digitales con ~85 colaboradores y 2.400 comercios. El soporte recibe ~350 consultas diarias.

## Requerimientos organizacionales
1. Responder consultas operativas, comerciales y normativas con precisión.
2. Reducir tiempos de primera respuesta y consultas repetitivas.
3. Mantener trazabilidad de fuentes documentales.
4. Escalar a humano cuando no hay evidencia suficiente.

## Objetivos medibles
- Primera respuesta ≤ 15 min (automatizada en segundos en prototipo).
- ≥ 85% respuestas con fuente verificable.
- ≥ 40% consultas frecuentes resueltas sin intervención humana.

## Alcance del prototipo
Chat académico con RAG interno/externo, API mock de transacciones y políticas de escalamiento. Datos 100% simulados.

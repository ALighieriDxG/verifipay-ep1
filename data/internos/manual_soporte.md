# Manual de Soporte VerifiPay v3.0

## 1. Activación de terminal de pago

Para activar una terminal VerifiPay T-100:
1. Encender el dispositivo y conectarlo a Wi-Fi.
2. Ingresar el código de comercio entregado por correo.
3. Esperar sincronización (2-5 minutos).
4. Realizar una venta de prueba por $100 CLP.

Si la terminal muestra **Error E-204**, significa falla de conexión con el servidor. Verificar red Wi-Fi y reiniciar el equipo. Si persiste más de 30 minutos, escalar a soporte nivel 2.

## 2. Links de cobro

Los links de cobro expiran a las **72 horas** desde su creación. El comercio puede regenerarlos desde el panel web en "Cobros > Nuevo link".

## 3. Conciliación de ventas

Las ventas con tarjeta de débito se abonan en **24 horas hábiles**. Las ventas con tarjeta de crédito se abonan en **48 horas hábiles**. Ventas realizadas viernes, sábado o domingo se depositan el **martes siguiente** antes de las 14:00 hrs.

## 4. Devoluciones

El comercio tiene un plazo máximo de **5 días hábiles** para procesar una devolución solicitada por el cliente. Montos superiores a $500.000 CLP requieren aprobación del supervisor de soporte.

## 5. Chargebacks

Un chargeback debe ser respondido en un plazo de **10 días hábiles** con evidencia de entrega o servicio. El equipo de cumplimiento revisa cada caso antes del envío al adquirente.

## 6. Escalamiento

Escalar a humano cuando: (a) el monto involucrado supera $500.000 CLP, (b) hay sospecha de fraude, (c) el comercio reporta más de 3 errores E-204 consecutivos en 24 horas.
